# ⚡ Nexus System Inspector & Pro Task Manager v4.0

A fast, zero-bloat Windows desktop utility that combines real-time hardware monitoring, intelligent process risk analysis, safe disk cleanup, and startup/service management in one portable executable.

## 🚀 Quick Start (No Installation Required)

1. Go to the **[Releases](../../releases)** section on the right and download **`nexus_monitor.exe`**.
2. Double-click **`nexus_monitor.exe`** to launch (accept the Windows Administrator prompt so the app can read hardware sensors, TPM status, and clean system caches).
3. No Python or external libraries are needed—everything runs standalone.

## ✨ What You Can Do With It

- **📊 Live Dashboard:** Track real-time CPU load, physical RAM usage, threads, and system uptime with 60-second live graphs.
- **💻 Deep Hardware Inspector:** View your exact Windows edition & build, laptop SKU/model, serial number, RAM stick manufacturer & DDR type, true GPU VRAM (>4 GB), Wi-Fi adapter, battery health, and TPM 2.0 status.
- **⚙️ Smart Process Manager:** Instantly spot what is safe to close (**🟢 Green**), what is background telemetry or running from suspicious folders (**🟡 Yellow**), and what is protected by Windows (**🔴 Red**).
- **🧹 Safe Disk Cleaner:** One-click cleanup of Windows/User temp files, browser caches (keeps passwords & cookies), update leftovers, and RAM standby memory—without touching your `Desktop` or `Downloads`.
- **🚀 Startup & Services Manager:** Disable unwanted startup apps and stop heavy third-party background services.

---
*Note: Because this is an independent open-source `.exe` packaged with PyInstaller, Windows SmartScreen may show an "Unknown Publisher" warning on first run. Click **More info → Run anyway** to proceed.*
